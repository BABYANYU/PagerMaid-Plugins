## 插件功能简介

| 插件             | 功能介绍                                                          |
| -------------- | ------------------------------------------------------------- |
| `LL.py`        | 调用指定 Telegram Bot 进行 URL 分析和 Ping 测试，并将 Bot 返回的图片结果转发到当前聊天。   |
| `bc.py`        | Telegram 消息保存与转存工具，支持回复消息、消息链接、批量/范围保存、受保护媒体转存以及保存媒体到 VPS 本地。 |
| `c.py`         | 查询机场订阅信息，可显示机场名称、已用流量、总流量、剩余流量及到期时间，并支持回复消息或批量查询多个链接。         |
| `cj.py`        | 查看当前已安装的 PagerMaid 插件及对应功能说明，并支持自定义插件备注。                      |
| `ck.py`        | Telegram Bot 自动签到工具，支持多任务管理、定时或随机时间签到、按钮签到及签到结果推送。            |
| `codex.py`     | 查询 Codex 使用额度，包括 5 小时额度、每周额度以及可用额度重置次数。                       |
| `codexai.py`   | 基于已登录的 Codex CLI 提供 AI 对话，支持模型与推理强度切换、回复上下文、图片分析及图片生成。        |
| `cz.py`        | 查询 Codex 最近两个月的额度重置记录，并按月份显示普通重置和储备重置。                        |
| `dc.py`        | 测试 PagerMaid 所在服务器到 Telegram DC1～DC5 的网络延迟，并显示当前账号所属 DC。      |
| `dme.py`       | 批量删除自己发送的历史消息，用于快速清理当前聊天中的个人消息。                               |
| `ds.py`        | 每日定时消息工具，可在指定聊天中设置每天固定时间自动发送指定内容。                             |
| `fanyi.py`     | 回复 Telegram 消息即可翻译为中文，优先使用 DeepL，失败时自动使用 Google 翻译。           |
| `huilv.py`     | 法币与加密货币汇率查询及金额换算工具，支持人民币、美元、USDT 等多种货币。                       |
| `ip.py`        | 查询 IP 或域名的地理位置、ISP、组织、ASN 及网络路由等信息。                           |
| `lianjie.py`   | 将代理节点或节点配置转换为 Mihomo YAML 订阅，并上传生成可直接使用的短链接。                  |
| `minimax.py`   | MiniMax AI 助手，支持文字问答、回复内容分析、图片理解、联网查询及图片生成。                   |
| `nq.py`        | 基于 Codex 的群聊自动回复工具，可针对全群或指定成员自动回复，并支持模型、推理强度和上下文管理。           |
| `pm.py`        | PagerMaid 插件管理工具，支持安装、覆盖、卸载、刷新、源码上传以及一键备份全部插件。                |
| `pmcaptcha.py` | Telegram 私聊防骚扰验证工具，陌生人需要通过验证码后才能正常私聊，并提供白名单及多种验证规则。           |
| `speedtest.py` | 基于 Ookla 的 VPS 网络测速工具，可测试上传、下载和延迟，并支持自动选择、指定服务器及附近服务器查询。      |
| `submanger.py` | Telegram 订阅管理工具，支持订阅的添加、查询、更新、删除、测活、仓库管理以及数据库备份恢复。            |
| `t.py`         | 将 `.yaml` / `.yml` 文件转换为 `.txt` 文件，文件内容保持完全不变，仅修改文件格式后缀。      |
| `xjj.py`       | 随机获取并发送短视频，视频优先由 Telegram 直接抓取，避免在 VPS 本地长期保存。                |
| `zhuanhuan.py` | 将代理节点或订阅链接同时转换为 Clash 和 Surge 可用的订阅链接。                        |
| `zj.py`        | 使用 MiniMax AI 总结当前群聊当天的聊天内容，自动整理重点信息并生成群聊总结。                  |
| `zt.py`        | 查看 PagerMaid 运行状态，包括 CPU、内存、插件数量、运行时间、Telegram DC 及网络延迟等信息。   |
