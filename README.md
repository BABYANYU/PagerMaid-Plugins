# PagerMaid-Pyro 插件集

| 插件 | 功能 |
| --- | --- |
| [ai.py](ai.py) | ChatGPT 问答、图片输入与 Codex 额度查询 |
| [api.py](api.py) | 查询星驰 API Key 的用量及余额 |
| [b.py](b.py) | 按时间范围导出群聊记录 |
| [bc.py](bc.py) | 批量保存或转存消息与媒体 |
| [c.py](c.py) | 查询机场订阅的流量与到期时间 |
| [cj.py](cj.py) | 查看已安装插件、功能备注与运行时间 |
| [ck.py](ck.py) | Telegram 机器人每日自动签到 |
| [codex.py](codex.py) | 查询 Codex 额度及重置次数 |
| [codexai.py](codexai.py) | 通过 Codex CLI 对话、分析图片与生成图片 |
| [cz.py](cz.py) | 按月查看 Codex 额度重置记录 |
| [dc.py](dc.py) | 查看账号所属 Telegram DC 及连接延迟 |
| [deepseek.py](deepseek.py) | DeepSeek 官方 API 问答与余额查询 |
| [dme.py](dme.py) | 批量清理自己的消息或收藏夹内容 |
| [ds.py](ds.py) | 定时发送消息或执行插件命令 |
| [dy.py](dy.py) | 查询 App 订阅与内购的低价地区 |
| [fanyi.py](fanyi.py) | 将回复的消息翻译成中文 |
| [git.py](git.py) | 监控 GitHub Releases 并推送更新 |
| [gp.py](gp.py) | 通过 ChatGPT OAuth 登录使用问答 |
| [huilv.py](huilv.py) | 查询汇率并换算金额 |
| [ip.py](ip.py) | 查询 IP 或域名的网络与归属信息 |
| [jg.py](jg.py) | 查询 ChatGPT Plus 和 Claude Pro 报价 |
| [lianjie.py](lianjie.py) | 生成永久 Mihomo 订阅链接，需 YANYU Sub 令牌 |
| [LL.py](LL.py) | 调用 Telegram 机器人测试 URL 和 Ping |
| [minimax.py](minimax.py) | MiniMax 问答、联网搜索与图片生成 |
| [music.py](music.py) | 搜索歌曲并获取 FLAC 下载链接 |
| [nq.py](nq.py) | 使用 Codex 为群聊自动回复 |
| [pm.py](pm.py) | 安装、卸载、刷新、上传与备份插件 |
| [pmcaptcha.py](pmcaptcha.py) | 陌生人私聊验证码与白名单 |
| [reload.py](reload.py) | 通过本地文件桥接热刷新插件 |
| [sj.py](sj.py) | 在 Telegram 昵称中显示时间与天气 |
| [speedtest.py](speedtest.py) | 使用 Ookla 测速并生成结果图卡 |
| [submanger.py](submanger.py) | 管理、测活和备份订阅 |
| [t.py](t.py) | 将 YAML 文件改为 TXT，保留原内容 |
| [workbuddy.py](workbuddy.py) | WorkBuddy 问答与 DeepSeek 用量查询 |
| [xjj.py](xjj.py) | 随机获取短视频 |
| [zhuanhuan.py](zhuanhuan.py) | 生成 Surge 和 Mihomo 永久订阅链接，需 YANYU Sub 令牌 |
| [zj.py](zj.py) | 使用 MiniMax 总结当天的群聊消息 |
| [zt.py](zt.py) | 查看服务器资源、运行时间与 Telegram 延迟 |
